# บทที่ 3 วิธีการดำเนินงาน (Methodology & System Architecture)

**ชื่อโครงงาน:** ระบบสนับสนุนความปลอดภัยส่วนบุคคลบนสมาร์ตโฟน (Personal Safety Support System on Smartphone)  
**ชื่อแอปพลิเคชัน:** BANTAWAN (SOS Premier)

---

## 💡 ข้อแตกต่างในการทำบล็อกไดอะแกรม (เทียบกับงาน IoT/Hardware)

*   **งาน IoT (ตัวอย่างในรูปภาพ):** เน้นแสดงการไหลของข้อมูลจากอุปกรณ์เซนเซอร์ฮาร์ดแวร์ $\rightarrow$ ไมโครคอนโทรลเลอร์ (ESP8266) $\rightarrow$ โปรโตคอล (MQTT) $\rightarrow$ เซิร์ฟเวอร์/ฐานข้อมูล $\rightarrow$ เว็บไซต์
*   **งานแอปพลิเคชันสมาร์ตโฟน (โปรเจกต์ BANTAWAN):** เน้นแสดงการทำงานของเลเยอร์ในแอป (App Architecture Layer), การประมวลผลเซนเซอร์ในตัวเครื่องสมาร์ตโฟน, การเชื่อมต่อแบบ **P2P Mesh Network ไร้เซิร์ฟเวอร์ (Off-Grid)** และการเชื่อมต่อ **REST APIs ภายนอก (On-Grid)**

---

## 3.2 ภาพรวมการทำงานโหมดไร้สัญญาณสื่อสาร (Off-Grid P2P Mesh Communication)

แผนภาพแสดงการไหลของข้อมูลแชตและการขอความช่วยเหลือฉุกเฉินไร้อินเทอร์เน็ต ผ่านโปรโตคอล P2P Mesh Network:

```text
  [ผู้ประสบภัย (เครื่อง A)]                  [ผู้ส่งต่อ (เครื่อง B)]                 [ศูนย์กู้ภัย/ผู้รับ (เครื่อง C)]
 ┌───────────────────────┐                 ┌───────────────────────┐                 ┌───────────────────────┐
 │ 1. กรอกข้อความ SOS     │                 │ 4. รับแพ็กเกจข้อมูล    │                 │ 6. รับแพ็กเกจข้อมูล    │
 │ 2. เข้ารหัสลับ E2EE    │                 │    ตรวจสอบ Message ID │                 │    ตรวจสอบ HMAC Sign  │
 │    (SHA-256 + HMAC)   │                 │    (ป้องกันการส่งซ้ำ)  │                 │    ถอดรหัสลับ E2EE    │
 │ 3. ส่งผ่าน BLE / Wi-Fi│ ───(Hop 1)───►  │ 5. ลดค่า TTL (เหลือ 4)│ ───(Hop 2)───►  │ 7. แสดงผลบน UI        │
 │    Direct (TTL = 5)   │                 │    กระจายส่งต่อข้อความ│                 │    พร้อมเปิดเสียงไซเรน│
 └───────────────────────┘                 └───────────────────────┘                 └───────────────────────┘
```

## 3.3 ภาพรวมการทำงานโหมดออนไลน์และการดึงข้อมูลเว็บเอพีไอ (On-Grid REST APIs Flow)

แผนภาพแสดงการดึงข้อมูลจากบริการภายนอกมาแสดงผลบนแอปพลิเคชัน:

```text
                                       ┌───────────────────────────────────┐
                                       │ 1. Longdo Map API                 │
                                       │    (POI โรงพยาบาล & เลเยอร์จราจร) │
                                       └─────────────────┬─────────────────┘
                                                         │ (HTTP GET)
                                                         ▼
┌──────────────────┐    HTTP Request    ┌───────────────────────────────────┐
│                  │ ─────────────────► │ 2. Overpass API (OpenStreetMap)   │
│                  │                    │    (พิกัดสถานพยาบาลในต่างประเทศ)   │
│                  │ ◄───────────────── └─────────────────┬─────────────────┘
│                  │    JSON Response                    │ (HTTP POST)
│   สมาร์ตโฟน      │                                     ▼
│   แอปพลิเคชัน    │ ─────────────────► ┌───────────────────────────────────┐
│   BANTAWAN       │                    │ 3. OSRM Routing API               │
│                  │ ◄───────────────── │    (คำนวณเส้นทางนำทางเลี้ยวต่อเลี้ยว) │
│ (Flutter UI Layer│                    └─────────────────┬─────────────────┘
│  + Map Cache)    │                                     │ (HTTP GET)
│                  │ ─────────────────►                  ▼
│                  │                    ┌───────────────────────────────────┐
│                  │ ◄───────────────── │ 4. Open-Meteo Weather & Air API   │
└──────────────────┘                    │    (ดึงสภาพอากาศ & ฝุ่น PM 2.5)    │
                                        └───────────────────────────────────┘
```
