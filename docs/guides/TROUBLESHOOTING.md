# คู่มือแก้ปัญหาทางเทคนิคและข้อขัดข้อง (Troubleshooting Guide)

เอกสารนี้รวบรวมข้อขัดข้องทั่วไปทางเทคนิคที่อาจเกิดขึ้นระหว่างติดตั้ง ทดสอบ หรือใช้งานจริงของแอปพลิเคชัน **BANTAWAN** พร้อมแนวทางแก้ไข

---

## 1. ปัญหาด้านการสื่อสารไร้เน็ต (Mesh P2P Connection Issues)

### อาการ: สแกนหาโหนดผู้อื่นไม่พบ หรือจับคู่ในห้องแชทไม่ได้
*   **สาเหตุที่ 1**: ไม่เปิดใช้งาน Bluetooth หรือ Wi-Fi ของเครื่องโทรศัพท์มือถือ
    *   *แนวทางแก้ไข*: เปิดการตั้งค่า Bluetooth และ Wi-Fi (ระบบ Nearby Connections ต้องการทั้งสองเสาสัญญาณเพื่อสแกนและประมวลผลข้อมูล P2P)
*   **สาเหตุที่ 2**: ไม่ได้เปิดใช้งานการระบุพิกัดตำแหน่ง (Location Service) ของโทรศัพท์มือถือ
    *   *แนวทางแก้ไข*: ต้องเปิดใช้ GPS บนเครื่องโทรศัพท์ เนื่องจากระบบปฏิบัติการ Android บังคับให้การสแกนคลื่น Bluetooth จำเป็นต้องระบุตำแหน่งพิกัดคู่ขนานเพื่อความปลอดภัย
*   **สาเหตุที่ 3**: การขาดสิทธิ์ขออนุญาตพิเศษใน Android 12 ขึ้นไป (Bluetooth Permission)
    *   *แนวทางแก้ไข*: ตรวจสอบว่าได้ยืนยันรับสิทธิ์ "ค้นหาและสแกนอุปกรณ์บลูทูธใกล้เคียง" แล้ว โดยเปิดการตั้งค่าแอปพลิเคชัน (App Info) -> สิทธิ์ (Permissions) -> อนุญาตสิทธิ์บลูทูธทั้งหมด

---

## 2. ปัญหาเกี่ยวกับแผนที่และระบบระบุพิกัด (Map & GPS Issues)

### อาการ: แผนที่เป็นช่องตารางสีดำว่างเปล่า ไม่มีเส้นภาพถนนปรากฏ
*   **สาเหตุที่ 1**: เครื่องผู้ใช้ขาดสัญญาณอินเทอร์เน็ต และไม่มีข้อมูลแผ่นแผนที่เก็บในหน่วยความจำเครื่อง
    *   *แนวทางแก้ไข*: ตรวจสอบว่าเคยกดดาวน์โหลดแผนที่ออฟไลน์เก็บไว้หรือไม่ หากต้องการใช้งานโดยไม่มีเน็ตอย่างเสถียร ให้ต่อเครือข่าย Wi-Fi/4G แล้วไปที่หน้า Profile -> เลือกตั้งค่าดาวน์โหลดแผนที่เก็บไว้ก่อนเดินทาง
*   **สาเหตุที่ 2**: ระบบไม่เข้าถึงพิกัด GPS ผู้ใช้ทำให้แสดงผลศูนย์กลางแผนที่ผิดจุด
    *   *แนวทางแก้ไข*: ยืนยันสิทธิ์ Location Access แบบ "อนุญาตตลอดเวลา" (Allow Always) หรือ "อนุญาตขณะเปิดใช้งาน" (Allow while using app)

### อาการ: กดขอนำทาง (Directions) แล้วหน้าจอโหลดค้าง หรือเกิด SnackBar แจ้งข้อผิดพลาดเส้นทางล้มเหลว
*   **สาเหตุ**: เซิร์ฟเวอร์ประมวลผลเส้นทาง OSRM สาธารณะอาจมีภาระคำร้องขอหนาแน่น (Rate Limiting) หรือเครื่องขาดอินเทอร์เน็ต
    *   *แนวทางแก้ไข*: ระบบนำทางเลี้ยวต่อเลี้ยว OSRM ต้องใช้เครือข่ายอินเทอร์เน็ตในการส่งคำขอประมวลผล หากใช้งานแบบออฟไลน์เต็มรูปแบบ (Off-grid) แนะนำให้ใช้ตัวชี้ทิศทางเข็มทิศพิกัดตรง (Bearing Compass) ใน **Hike Mode** เพื่อนำทางเชิงเส้นกลับแทน

## 3. ปัญหาระบบแจ้งเตือนภัยและตัวนับถอยหลัง Safety Check-in

### อาการ: ตัวนับถอยหลัง (Timer) หมดเวลาแต่ไม่มีเสียงไซเรน หรือไม่มี Notification สัญญาณเตือนแจ้งขึ้นจอ
*   **สาเหตุที่ 1**: แอปพลิเคชันไม่ได้สิทธิ์แสดงการเตือน (Notification Permission)
    *   *แนวทางแก้ไข*: เปิดการตั้งค่าโทรศัพท์และอนุญาตการแจ้งเตือนจากแอป BANTAWAN
*   **สาเหตุที่ 2**: ระบบจัดการแบตเตอรี่เบื้องหลังของโทรศัพท์ สั่งปิดการทำงานแอปเมื่อจอล็อก (Doze Mode / Battery Optimization)
    *   *แนวทางแก้ไข*: เข้าตั้งค่า Battery Optimization บน Android ของแอปนี้ เปลี่ยนสถานะเป็น "ไม่ต้องประหยัดพลังงาน" (Unrestricted) เพื่ออนุญาตให้ตัวสแกนนับเวลาเบื้องหลังทำงานได้ไม่ขาดช่วง
