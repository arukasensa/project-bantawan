# ขอบเขตของโครงงาน (Project Scope)

**ชื่อโครงงาน:** ระบบสนับสนุนความปลอดภัยส่วนบุคคลบนสมาร์ตโฟน (Personal Safety Support System on Smartphone)  
**ชื่อแอปพลิเคชัน:** BANTAWAN (SOS Premier)  

---

## 1. ขอบเขตด้านฮาร์ดแวร์และระบบปฏิบัติการ (Hardware & OS Scope)
1.  **ระบบปฏิบัติการ:** รองรับการทำงานบนสมาร์ตโฟนระบบปฏิบัติการ **Android (Android 5.0 Lollipop / API Level 21 ขึ้นไป)** และ **iOS (iOS 12.0 ขึ้นไป)**
2.  **การเข้าถึงฮาร์ดแวร์อุปกรณ์ (Hardware Access):**
    *   **GPS Receiver:** ระบุตำแหน่งพิกัดละติจูด ลองจิจูด และความแม่นยำทางภูมิศาสตร์
    *   **Magnetometer Sensor:** อ่านค่าสนามแม่เหล็กโลกเพื่อแสดงผลเข็มทิศดิจิทัล (Digital Compass)
    *   **Flashlight LED:** ควบคุมการเปิด/ปิดและกระพริบไฟฉายกล้องตามรหัสสัญญาณมอร์ส (SOS Morse Code)
    *   **Audio Speaker:** เล่นสัญญาณเสียงไซเรนฉุกเฉินความถี่สูง และส่งเสียงสังเคราะห์ผ่านระบบ Text-to-Speech
    *   **Battery Power Sensor:** ตรวจวัดระดับพลังงานแบตเตอรี่คงเหลือและสถานะการชาร์จ

---

## 2. ขอบเขตด้านซอฟต์แวร์และสถาปัตยกรรม (Software Architecture Scope)
1.  **การพัฒนาแอปพลิเคชัน:** พัฒนาด้วย **Flutter SDK (ภาษา Dart)** และใช้ **Provider Pattern** ในการจัดการ State ของแอปพลิเคชัน
2.  **สถาปัตยกรรม Offline-First:** รองรับการเปิดใช้งานและเรียกดูข้อมูลสำคัญได้ 100% แม้ไม่มีสัญญาณอินเทอร์เน็ต และซิงโครไนซ์ข้อมูลเมื่อกลับมาเชื่อมต่อออนไลน์
3.  **ระบบสื่อสารไร้เซิร์ฟเวอร์ (Off-Grid Mesh Network):**
    *   ประยุกต์ใช้ **Google Nearby Connections API** โหมด `Strategy.P2P_CLUSTER`
    *   สื่อสารผ่าน **Bluetooth Low Energy (BLE)** และ **Wi-Fi Direct / Wi-Fi SoftAP** เพื่อส่งต่อข้อความ (Multi-hop Relay) ในรัศมีอุปกรณ์ใกล้เคียง
4.  **ระบบความปลอดภัยและการเข้ารหัส (Security & Cryptography):**
    *   เข้ารหัสข้อความแบบ **End-to-End Encryption (E2EE V2)** ด้วยอัลกอริทึม **SHA-256 Key Derivation Function (KDF)**
    *   ตรวจสอบความถูกต้องของข้อความและป้องกันการดัดแปลง (Anti-Tampering Verification) ด้วย **HMAC-SHA256**

---

## 3. ขอบเขตด้านระบบสารสนเทศภูมิศาสตร์และบริการภายนอก (GIS & External APIs Scope)
1.  **แผนที่และการแสดงผล:** ใช้ไลบรารี **`flutter_map`** ในการเรนเดอร์แผนที่แบบ Interactive พร้อมระบบแคชแผ่นแผนที่ (Tile Caching) ในตัวเครื่อง
2.  **บริการเชื่อมต่อ API ภายนอก:**
    *   **Longdo Map API:** ค้นหาตำแหน่งสถานพยาบาล (Hospital POI), รายงานเหตุการณ์อุบัติเหตุ และเลเยอร์สภาพการจราจรในประเทศไทย
    *   **Overpass API (OpenStreetMap):** ค้นหาตำแหน่งสถานพยาบาลฉุกเฉินและร้านขายยานอกเขตประเทศไทยหรือจุดที่ Longdo ไม่ครอบคลุม
    *   **OSRM Routing API:** คำนวณเส้นทางขับขี่ที่เร็วที่สุดและถอดรหัส Polyline เพื่อนำทางแบบเลี้ยวต่อเลี้ยว (Turn-by-turn Navigation)
    *   **Open-Meteo Weather & Air Quality API:** ดึงข้อมูลสภาพอากาศ อุณหภูมิ ดรรชนีฝุ่นละออง PM 2.5 และสารเคมีในบรรยากาศ
    *   **Photon & Nominatim Geocoding APIs:** แปลงข้อความค้นหาชื่อสถานที่ภาษาไทยเป็นพิกัดละติจูด/ลองจิจูด

---

## 4. ขอบเขตด้านฟังก์ชันการทำงานของผู้ใช้ (Functional Scope)
1.  **ระบบสื่อสารแชตฉุกเฉิน (Nearby Mesh Chat):**
    *   ส่งข้อความ พิกัดตำแหน่งปัจจุบัน และสัญญาณขอความช่วยเหลือ (SOS) ไปยังผู้ใช้คนอื่นในเครือข่าย P2P Mesh
    *   แสดงรายการผู้ใช้อยู่รอบตัว (Online Nearby Peers) และสถานะการเชื่อมต่อ
2.  **ระบบนำทางและค้นหาสถานพยาบาล (Emergency Map & Facility Finder):**
    *   แสดงหมุดโรงพยาบาล คลินิก และร้านขายยาบนแผนที่
    *   มีปุ่มคำนวณเส้นทางนำทาง (Routing) ไปยังสถานพยาบาลที่เลือกทันที
3.  **ระบบศูนย์คู่มือปฐมพยาบาล (First Aid Emergency Center):**
    *   แสดงขั้นตอนการปฐมพยาบาลเบื้องต้นแบ่งตามหมวดหมู่ภัยพิบัติ/การบาดเจ็บ
    *   มีปุ่มกดอ่านออกเสียงคำสั่งปฐมพยาบาลด้วยเสียง (Text-to-Speech Voice Guidance)
4.  **ระบบเครื่องมือช่วยเหลือฉุกเฉิน (Emergency Utility Tools):**
    *   เปิด/ปิดไฟฉาย SOS Morse Code และไฟฉายส่องสว่างปกติ
    *   ส่งเสียงไซเรนฉุกเฉินความถี่สูงเพื่อส่งสัญญาณเรียกทีมกู้ภัย
    *   เข็มทิศดิจิทัลระบุทิศทางแม่เหล็กโลก
    *   ฟังก์ชันบันทึกพิกัดปลอดภัยล่าสุด (Last Safe Point) และเช็กสถานะความปลอดภัย (Safety Check-in)
5.  **ระบบข้อมูลส่วนตัวและสายด่วนฉุกเฉิน (Profile & Emergency Speed Dial):**
    *   บันทึกข้อมูลกรุ๊ปเลือด โรคประจำตัว ยาที่แพ้ และข้อมูลผู้ติดต่อฉุกเฉิน
    *   มีปุ่มโทรด่วนไปยังเบอร์ฉุกเฉินหลักของประเทศไทย (เช่น 1669 การแพทย์ฉุกเฉิน, 191 แจ้งเหตุด่วนเหตุร้าย, 199 ดับเพลิง)

---

## 5. ข้อจำกัดของโครงงาน (Project Limitations)
1.  **ระยะการสื่อสาร P2P Mesh Network:** ระยะการรับส่งข้อความขึ้นอยู่กับกำลังส่งและประสิทธิภาพฮาร์ดแวร์บลูทูธและ Wi-Fi ของสมาร์ตโฟนแต่ละรุ่น (โดยเฉลี่ย 10–100 เมตรต่อโหนด)
2.  **การดึงข้อมูลออนไลน์:** ข้อมูลสภาพอากาศ PM 2.5 สภาพการจราจร และการคำนวณเส้นทาง OSRM ต้องใช้อินเทอร์เน็ต ณ ขณะดึงข้อมูล หากอยู่ในสภาวะ Off-Grid แอปจะแสดงผลข้อมูลล่าสุดที่บันทึกไว้ในระบบแคช (Cache Data)
3.  **บัญชีบริการภายนอก:** รหัส API Key ของ Longdo Map API ที่ใช้งานในโปรเจกต์เป็นบัญชีทดสอบสาธารณะเพื่อวัตถุประสงค์ทางการศึกษาและการทดสอบโครงงาน
